Bible study on your machine

Trivia, reading, and practice that keep working offline.

You install once. Daily questions, BSB, WEB, and KJV texts, and profiles stay on this computer.

How you use it

Four moments inside the desktop app.

  1. 1.0

    Open today’s question

    One prompt lands each day. On Mac, set a reminder and watch the dock badge until you answer.

  2. 2.0

    Read without a signal

    BSB, WEB, and KJV ship inside the install. You open the reader and keep going when the network drops.

  3. 3.0

    Keep a local profile

    XP, streaks, medals, highlights, and biblical avatars live in your user data folder. Updates do not wipe them.

  4. 4.0

    Play with friends online

    Sign in from the desktop app to add friends and run live trivia against each other. Study and reading still work with no account.

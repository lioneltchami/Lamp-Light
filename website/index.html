What you get

Trivia, practice modes, and a full Bible reader. Start without an account.

  • Daily question

    Answer one question each day. On Mac, set a reminder and see a dock badge when today is still open.

  • Offline Bibles

    BSB, WEB, and KJV ship inside the install, so you read with no connection.

  • Trivia and practice

    Work through a fixed question bank. Scores and answers stay on disk.

  • Local profiles

    Track XP, streaks, medals, highlights, and biblical avatars on this machine.
